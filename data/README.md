# Dossier de données

- `data/input/` contient les fichiers fictifs utilisés par les tests et les exemples.
- `data/output/` contient les artefacts générés par les simulations : graphiques et exports.
- Les jeux de données fictifs peuvent être versionnés dans le dépôt.
- Les jeux de données réels doivent être anonymisés avant toute utilisation ou transmission.

**Règle de confidentialité :** ne jamais ajouter de données personnelles, confidentielles ou issues
d'un projet réel dans ce dépôt.
