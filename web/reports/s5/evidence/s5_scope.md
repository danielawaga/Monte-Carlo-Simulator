# Périmètre S5 retenu

La feuille de route initiale décrivait la semaine 5 comme une marge destinée aux retours et aux extensions. Les éléments attestés entre le 15 et le 17 août 2026 montrent que cette marge a été utilisée pour :

- améliorer l’interface Streamlit et l’export Excel ;
- rendre les hypothèses importées modifiables ;
- ajouter des graphiques interactifs avec lecture des valeurs exactes ;
- construire une interface React, TypeScript et Vite séparée du moteur Python ;
- structurer les parcours Configuration, Résultats et Comparaison de scénarios ;
- étendre ensuite la navigation aux fonctions de pilotage, gouvernance et administration.

La logique probabiliste reste destinée au moteur Python. Les données de l’interface React actuelle sont des données de démonstration isolées dans la couche frontend ; la connexion complète au backend demeure une étape S6.
